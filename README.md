## About

I'm **Shiyuan (Dennis) Lyu**, a Computer Science Specialist at the **University of Toronto**.

I’m interested in building reliable AI systems and studying how software-engineering tools behave beyond surface-level correctness — from structured LLM pipelines and agent tooling to coding-agent evaluation.

Currently exploring **AI systems, software engineering research, and research tooling**, while building projects that are useful, reproducible, and easy to inspect.

## Selected work

### [Patch-Scope Validity Artifact](https://github.com/kkkaa43/patch-scope-validity-artifact)

An evidence-first research artifact for studying whether coding-agent patches satisfy declared edit-scope contracts in addition to passing tests.

`Python` `Coding Agents` `Software Engineering Research` `Reproducibility`

### [Academic Literature Knowledge Graph](https://github.com/kkkaa43/llm-literature-knowledge-graph)

An end-to-end research application for arXiv discovery, PDF parsing, schema-validated LLM extraction, and interactive knowledge-graph exploration.

`Python` `Streamlit` `LLM APIs` `NetworkX` · [Live demo](https://llm-literature-kg.streamlit.app/)

### [Trippy — Intelligent Desktop Trip Planner](https://github.com/emilyzyy/207)

A Java desktop trip-planning application built with Clean Architecture, combining scheduling constraints, weather-aware planning, maps, shared itineraries, and an AI trip assistant.

`Java` `Swing` `Clean Architecture` `Maven` `JUnit 5`

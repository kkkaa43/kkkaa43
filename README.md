### [Gomoku AI with Minimax Search](https://github.com/kkkaa43/gomoku-ai)

A playable Gomoku game featuring a search-based AI opponent and an interactive Pygame interface.

**Highlights:** minimax search, alpha-beta pruning, move ordering, candidate-move filtering, transposition-table caching, tactical win detection, and heuristic board evaluation.
